A two-line robot confession for the [make.fun bounty "The Robot Apology"](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59).

Line one owns one specific mistake: a robot that watered a plastic fern 214 times since March because its leaves never wilted. Line two names the lesson that follows from that exact mistake: check whether a plant is alive before watering it.

Run with `node main.ts`; it writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
